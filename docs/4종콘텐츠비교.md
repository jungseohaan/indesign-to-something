## 12. AST 설계: 교과서 vs 문제집 — 근본적 차이

### 문제집 (C, D) → "구조화된 콘텐츠" AST

```
Document
├── Problem[]
│   ├── source (년도/출처) — D만
│   ├── sidebar (보조단) — C만
│   ├── question
│   │   ├── stem (발문)
│   │   ├── figure (그래프/표)
│   │   ├── box (<보기>) — D만
│   │   └── choices (①②③④⑤)
│   └── solution (교사용 풀이)
```

### 교과서 (A, B) → "페이지 기반 멀티레이어" AST

```
Document
├── Unit (단원)
│   ├── UnitOpener (단원시작)
│   │   ├── title, objectives, opener_activity
│   │   └── decorations (말풍선, 캐릭터, 삽화)
│   ├── Section[] (소단원)
│   │   ├── TextPassage (본문 지문) ← B 국어 고유
│   │   ├── Activity[] (탐구/활동)
│   │   │   ├── prompt (발문)
│   │   │   ├── concept_box (개념정리)
│   │   │   ├── chart/table (도표)
│   │   │   ├── sidebar (보조단)
│   │   │   └── student_area (빈칸/체크리스트)
│   │   ├── Application (적용)
│   │   └── SectionReview (소단원 마무리)
│   │       ├── self_check (스스로 점검)
│   │       └── practice (문제)
│   ├── ReadingActivity (즐겁게 읽기) ← B 국어 고유
│   ├── VocabActivity (어휘력 키우기) ← B 국어 고유
│   ├── CreativeActivity (창의융합)
│   └── UnitReview (단원 마무리)
```

**→ 교과서 AST는 "교육과정 구조"를 반영해야 하므로, 문제집 AST와 근본적으로 다름.**

## 13. 최종 개발 로드맵

### Phase 0: 풀수록 수학 (1~2주) — Quick Win
```
Target: 4×1 Table → ProblemNode → HWPX
Key: NP_ 28종 폰트 매핑, 18개 스타일 매핑
Risk: Low (가장 규칙적)
```

### Phase 1: 풀수록 물리 확장 (1~2주)
```
Target: 11×2/10×2/7×2 Table + Nested Table → ProblemNode → HWPX
Key: BT수식H 매핑, 분수 문단스타일 쌍, Anchored Figure
Risk: Medium (다양한 Table 패턴, nested table)
```

### Phase 2: 수학 교과서 (2~3주)
```
Target: 인라인 Story + 도형 기반 구조 → EducationalAST → HWPX
Key: BT수식M 매핑, 가짜 Table 감지, UXP resolved 통합
Risk: High (자유 레이아웃, 인라인 Story)
```

### Phase 3: 국어 교과서 (3~4주) — 가장 도전적
```
Target: 60+ 폰트 + 3,200+ 시각요소 + 비정형 콘텐츠 → EducationalAST → HWPX
Key: 
  - 102개 스타일 → 시맨틱 매핑 (수진 정리 27개 포함)
  - 134개 이미지 처리
  - 753개 Polygon + 640개 Line → 장식 vs 콘텐츠 분류
  - 30+ 디자인 폰트 → 이미지 폴백/대체 전략
  - 비정형 레이아웃 → 읽기 순서 추론
Risk: Very High (디자인 중심, 규칙 추출 어려움)
```

### 결론

| Phase | 대상 | 기간 | 난이도 | 비즈니스 가치 |
|-------|------|------|:------:|:------------:|
| 0 | 풀수록 수학 | 1~2주 | ★★☆ | ★★★★★ |
| 1 | 풀수록 물리 | 1~2주 | ★★★ | ★★★★☆ |
| 2 | 수학 교과서 | 2~3주 | ★★★★ | ★★★☆☆ |
| 3 | **국어 교과서** | **3~4주** | **★★★★★** | ★★★☆☆ |

**국어 교과서는 IDML 변환 파이프라인의 "최종 보스"입니다.**
풀수록 → 수학교과서 → 국어교과서 순서로 점진적 복잡도 확장이 유일하게 합리적인 전략.
