# Teaching Semantic Pipeline

이 디렉터리의 교수자료 생성 프롬프트는 2-agent 구조로 실행된다.

실제 실행 프롬프트:

1. `agent_a_prompt.txt`
   - InDesign AST chunk를 입력받는다.
   - `semantic_blocks`만 생성한다.

2. `agent_b_prompt.txt`
   - Agent A가 만든 Semantic Block 목록을 입력받는다.
   - `teaching_blocks`만 생성한다.

호출 방식은 기존과 동일하게 `--teach prompts/base_prompt.txt`를 사용할 수 있다.
코드는 같은 디렉터리의 `agent_a_prompt.txt`, `agent_b_prompt.txt`를 자동으로 로드한다.
